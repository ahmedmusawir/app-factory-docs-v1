1502: ### G4: `clearMocks` doesn't reset implementations
1503: 
1504: `clearMocks: true` in `jest.config.js` clears `mock.calls` and `mock.results`, NOT `mockImplementation` or `mockReturnValue`. A return value set via `.mockReturnValue()` persists across tests unless explicitly reset.
1505: 
1506: For per-test configuration that varies, prefer `mockReset()` (clears history + implementation) over `clearMocks`.
1507: 
1508: ### G5: Webhook acknowledgment follows durable acceptance
1509: 
1510: A webhook acknowledges success only after checked completion of the required state transition or checked durable capture/enqueue. Failure before that boundary returns a retryable non-success. Failure after durable acceptance is recovered through bounded durable retries, visible failed work, reconciliation and a named recovery owner; it does not retroactively invalidate the acknowledgment. Test status and persisted outcome for pre-acceptance failure, post-acceptance failure, duplicates and recovery.
